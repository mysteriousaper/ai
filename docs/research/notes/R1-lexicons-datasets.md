# R1 - Emotion lexicons, datasets and licences

Researcher notes, 2026-11-18. Scope: assignment R1 (11 resource groups).
Method: `curl -sIL` HEAD checks for every URL on reachable hosts; small files (<30 MB) were fetched to read READMEs/schemas; licence sentences quoted from the file or page named. WebFetch cannot resolve any host outside the allowlist, so non-allowlisted pages were reachable only through WebSearch summaries (marked `single-source / search-summary`).

## Summary
- Only **EmoBank (CC BY-SA 4.0)** and **GoEmotions (Apache-2.0 on the labels; underlying text is Reddit)** are usable commercially without a negotiation; both carry caveats (see below).
- **All NRC resources** (VAD v1/v2.1, EmoLex, Emotion Intensity, SemEval-2018 Task 1 data) are free for non-commercial research only. NRC states a commercial licence exists ("a small fee"), via email to the author. Redistributing the data (e.g. shipping it inside a product) is forbidden without that licence. Class: `needs-licence`.
- **NRC VAD scales:** v2.1 = **[-1, 1]** (verified: min -1.000, max 1.000 in the file; 54,801 entries). v1 = **0..1** (README: "in version 1, the default form of the lexicon had scores from 0 to 1").
- **Warriner 2013:** the official host `crr.ugent.be` is **gone** (site removed; "under reconstruction"). Only third-party GitHub mirrors are reachable. Original licence reported (secondary source) as **CC BY-NC-ND 3.0** -> `research-only`.
- **ANEW, ISEAR, EmoSurv, EmpatheticDialogues, DailyDialog**: ANEW needs a signed user agreement; EmpatheticDialogues (CC BY-NC 4.0), DailyDialog (CC BY-NC-SA 4.0), EmoSurv (non-commercial grant) are `research-only`; ISEAR licence not found (`unclear`).
- **Russian:** CEDR (Apache-2.0 repo, but texts from LiveJournal/Lenta.ru/Twitter -> provenance `unclear`); ru_go_emotions (MIT tag on a Google-Translate copy of GoEmotions - fine in principle if GoEmotions is fine); RuSentiLex not retrievable from here. No Russian VAD norms with a verified open licence found (ENRuN, 1000-word norms exist in papers only).
- **Armenian:** no emotion-labelled corpus with an open licence found. Leads: Chen & Skiena sentiment lexicon (hy: 720 pos + 937 neg words; GPL-3.0 -> incompatible with proprietary distribution), `nigkal/ArmenianNLP` (sentiment + emotion lexicons, CC BY-NC 4.0, not inspectable from this session), gated HF `Elen22/Armenian-news-sentiment-dataset` (956 test examples). NRC lexicons also exist in Armenian via Google Translate (same NRC terms).
- **Network gaps for the user to decide:** `storage.googleapis.com` turned out reachable (GoEmotions raw CSVs); not reachable: `csea.phhp.ufl.edu` (ANEW), `ieee-dataport.org` (EmoSurv), `labinform.ru` (RuSentiLex), `competitions.codalab.org` (SemEval page), `static-content.springer.com` (Warriner supplement), `arxiv.org`, `aclanthology.org`, `yanran.li` (DailyDialog original), `shop-magasin.nrc-cnrc.gc.ca` (NRC licence shop; 403 from proxy).

## 1. ANEW (Bradley & Lang 1999)
- 1,034 English words; pleasure/valence, arousal, dominance via Self-Assessment Manikin; **1-9** scale. (single-source / search-summary: https://www.scribd.com/document/42601042/Affective-Norms-for-English-Words ; counts agree with PROJECT_BRIEF.)
- Distribution: University of Florida CSEA, official page https://csea.phhp.ufl.edu/media/anewmessage.html (host unreachable from the container, HTTP 403). Per search summary: researchers fill in an "ANEW Researcher Information Form", then sign a User Agreement; access "within 30 days"; CSEA asks that colleagues be referred to the centre rather than sharing the files. The exact licence wording was **not retrievable** (not found).
- Class: `needs-licence` (request-only with a signed agreement; commercial terms unknown). Superseded for our purposes by Warriner/NRC; recommend skipping.
- Access: `manual`. User must submit the form on the CSEA page and sign the agreement (and ask whether commercial use is allowed) - low priority.

## 3. NRC VAD Lexicon v2.1 / v1
- Homepage: https://saifmohammad.com/WebPages/nrc-vad.html
- **v2.1** (released March 2025; v2.0 limited release Oct 2024): ~55k English terms. Verified in file `NRC-VAD-Lexicon-v2.1.txt`: 54,801 rows, tab-separated `term valence arousal dominance`, min -1.000 / max 1.000. ~44.7k unigrams (`Unigrams/`) and ~10k MWEs (`MWE/`), also OneFilePerDimension and PolarSubset (|score| >= 0.333). Contains PDFs of papers. v1 entries were rescaled to [-1,1] inside the v2 file; v2-added entries were rated by Likert ("The additional entries for v2 were created using a Likert Rating scale"), v1 entries by best-worst scaling. README: "the scores range from -1 (lowest V/A/D) to 1 (highest V/A/D)".
  - https://saifmohammad.com/WebDocs/Lexicons/NRC-VAD-Lexicon-v2.1.zip  (HEAD 200, 6,488,651 bytes)
- **v1** (July 2018, README updated Aug 2022): >20,000 English words; scores **0 to 1** ("For a given word and a dimension (V/A/D), the scores range from 0 ... to 1"; v2 README: "in version 1, the default form of the lexicon had scores from 0 to 1"). The v1 zip also holds Google-Translate translations into 108 languages incl. **Russian and Armenian** (Aug 2022).
  - https://saifmohammad.com/WebDocs/Lexicons/NRC-VAD-Lexicon.zip (HEAD 200, 44,536,009 bytes; not downloaded)
- Licence quotes (README Terms of Use IX and the homepage "Terms of Use", https://saifmohammad.com/WebPages/nrc-vad.html):

  - "Commercial License: If interested in commercial use of the lexicon, contact the author: saif.mohammad@nrc-cnrc.gc.ca"
  - "Credit: If you use the lexicon in a product or application, then acknowledge this in the 'About' page ... stating the name of the resource, the authors, and NRC."
  - Download links are labelled "(Non-Commercial Use Only -- Research or Educational)".

## 4. NRC Emotion Lexicon (EmoLex) and NRC Emotion Intensity Lexicon
- **EmoLex**: https://saifmohammad.com/WebPages/NRC-Emotion-Lexicon.htm . Version 0.92 (public release 10 July 2011; README updated Aug 2022). 14,182 unigrams; 8 Plutchik emotions (anger, anticipation, disgust, fear, joy, sadness, surprise, trust) + negative/positive; binary 0/1 association (a ~25,000-sense version has not/weakly/moderately/strongly). Translations in 108 languages (Aug 2022).
  - https://saifmohammad.com/WebDocs/Lexicons/NRC-Emotion-Lexicon.zip (HEAD 200, 25,878,449 bytes; includes translations)
  - Full suite https://saifmohammad.com/WebDocs/Lexicons/NRC-Suite-of-Sentiment-Emotion-Lexicons.zip (109,250,110 bytes)
  - Licence: same terms as VAD (quote above: "Research Use ... non-commercial research and educational purposes", "No Redistribution", "Commercial License: If interested in commercial use of the lexicon, contact the author"). Class `needs-licence`.
- **NRC Emotion Intensity Lexicon** (bonus): https://saifmohammad.com/WebPages/AffectIntensity.htm . Version 1 (March 2020), ~10,000 entries, 8 emotions, real-valued **0 to 1** ("For a given word w and emotion e, the scores range from 0 to 1"). Earlier v0.5 (NRC-AIL) had 4 emotions.
  - https://saifmohammad.com/WebDocs/Lexicons/NRC-Emotion-Intensity-Lexicon.zip (HEAD 200, 29,608,461 bytes)
  - Licence: "Research Use: The lexicon mentioned in this page can be used freely for non-commercial research and educational purposes." / "No Redistribution ..." / "Commercial License: ... contact the author: saif.mohammad@nrc-cnrc.gc.ca". Class `needs-licence`.

## 11. Armenian
- **No emotion-labelled Armenian corpus with a clear open licence found.** Found (all low volume):
  - Chen & Skiena multilingual sentiment lexicon, code `hy`: 720 positive + 937 negative words (counted); quality is mediocre (first "positive" entries are "առաջին" = first, "մեծ" = big, "ավելի" = more).   - `nigkal/ArmenianNLP` (https://github.com/nigkal/ArmenianNLP; README, raw.githubusercontent, verified): "bring NLP resources for the Armenian language, including sentiment and emotion lexicons and an Armenian BERT"; licence "Creative Commons Attribution-NonCommercial 4.0 International". File list and lexicon sizes could not be inspected (repo not attached to this session; GitHub MCP denied). Class `research-only`. Related paper (search summary): "Armenian Sentiment Analysis and Emotion Recognition Using Bidirectional Deep Learning Models", AUB ScholarWorks.
  - HF `Elen22/Armenian-news-sentiment-dataset` (3-class sentiment; HF tag apache-2.0, **gated manual**). Per search summary: train/dev machine-translated (Google Translate) from SST, MELD, SLSD; test = 956 news articles hand-labelled (295 neg / 476 neu / 185 pos). Provenance of translated parts (SST, MELD) is non-commercial/research -> `unclear`. Access `manual`: log in to Hugging Face and accept the share-contact-information condition.
  - NRC VAD v1 and EmoLex Armenian translations (Google Translate, Aug 2022): NRC terms apply (`needs-licence`).
  - OpenSLR SLR153 Armenian news text, CC BY-SA 4.0 (search summary): unlabelled, usable only for pretraining/annotation.
  - HF `EdUarD0110/arm_sent_pairs_130k` (mit): despite the name it is a dialogue/sentence-pair set with no sentiment labels per its card.
- Conclusion (inference): Armenian affect will need translated lexicons + multilingual encoder, plus own annotated data (as PROJECT_BRIEF §9 already plans).

## Open questions / things the user must do
1. **NRC commercial licence** (decision + email): contact saif.mohammad@nrc-cnrc.gc.ca if the product will embed VAD v2.1, EmoLex, Emotion Intensity or use SemEval-2018 data commercially; ask price and whether trained models derived from the lexicons count as redistribution. Until then keep NRC behind the swappable-resource interface (research mode only).
2. **ANEW**: only if wanted - fill in CSEA form and sign User Agreement (low value; Warriner covers it).
3. **ISEAR**: download manually from the unige.ch CISA page and note its terms.
4. **EmoSurv**: free IEEE DataPort login, accept licence, download 4 CSVs into `data/raw/emosurv/` (non-commercial only).
5. **RuSentiLex**: download manually from labinform.ru and record licence.
6. **Armenian news sentiment (Elen22)**: Hugging Face login + accept conditions (optional).
7. **Warriner**: decide whether to rely on the third-party GitHub mirror (no licence file; original host dead) or write to Brysbaert for a commercial/derivative permission.
8. **Network decision (not changed by me):** `storage.googleapis.com` already resolves (needed for GoEmotions raw); the hosts above marked unreachable would only be needed for the manual items, which the user can download on their own machine.
9. Legal check suggested for GoEmotions (Reddit provenance) and EmoBank (ShareAlike + headline provenance) before selling.
