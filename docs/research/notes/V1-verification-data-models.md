# V1 - Verification of R1 (lexicons/datasets) and R2 (models)

Verifier notes, 2026-11-18. Checked against primary files and pages myself: NRC pages and the v2.1 zip,
EmoBank/XANEW/GoEmotions/EmpatheticDialogues READMEs and LICENSE files, the HF cards, `config.json` files and `/api/models` JSON.
I opened the scale files and parsed them. Download URLs were checked with HEAD only. Small files (<7 MB) were fetched into the
scratchpad to check scales; the NRC v1 zip was read through a range request on its central directory, with no full download.
Unreachable from this session (proxy 403 / DNS): `web.archive.org`, `link.springer.com`, `ieee-dataport.org`, so the Warriner
primary licence and the EmoSurv licence are still **unverified** (secondary only).

## Verdict summary

Counts over the 37 claims in the table: **verified 31, corrected 4, unverified 2, wrong 0**. (The NRC Emotion Intensity licence page was not re-fetched; its URL and size were.)

Most important corrections and flags:

1. **GoEmotions is not cleanly `commercial-OK`. Corrected to `unclear` for the corpus.** The only licence statement is
   repository-level. The HF card says "The GitHub repository which houses this dataset has an Apache License 2.0", and the
   google-research `goemotions/README.md` itself has no licence line. Google can license its labels. It cannot license
   the Reddit users' comment text, and the raw files carry Reddit usernames. Using the labels and training on them is
   ordinary practice, and the MIT/Apache model weights are still `commercial-OK` on their own licence. But do not
   redistribute GoEmotions text in a product, and get legal sign-off before selling. This provenance caveat flows down to
   **every recommended classifier** (SamLowe, Horizon-Labs, cirimus, fyaronskiy, seara), because they are all trained on GoEmotions text.
2. **BenRongey/deberta-v3-base-emobank-vad: R2's metrics are quoted correctly, but they are near-useless.** If the reported
   MAE is on the raw EmoBank 1-5 scale, A (MAE 0.191) and D (MAE 0.175) are **no better than always predicting the mean**.
   I computed mean-prediction MAE on the EmoBank test split: A 0.189, D 0.156. The card also says "fine-tuned ... on
   the None dataset", and its split and scale are undocumented. Do not use it even as a baseline. Train our own head.
3. **Horizon-Labs/multilingual-emotions-* licence verified (Apache-2.0 LICENSE + NOTICE with the mmBERT MIT notice).
   Trust is low.** The HF author listing shows the org's first model created 2026-09-23 and ~38 models published in about
   6 weeks. Base has 330 downloads. All metrics are self-reported from the author's own harness. Its comparison table
   also lists tabularisai at 135M params and CC-BY-NC-4.0, while the HF API gives 278.05M params and `license:mit` (card
   modified 2026-11-03). So the third-party table is not reliable for other models' licences or sizes. Treat the Russian
   BRIGHTER score of 0.657 as a claim to re-test, not a fact.
4. **NRC VAD v1 scale needs a qualifier.** The default v1 file is 0..1 (homepage: "the scores range from 0 (lowest V/A/D)
   to 1"), but the v1 zip **also ships a `BipolarScale/` folder** (a -1..1 version). R1 says only "0 to 1". Whichever file
   a loader reads decides the scale, so code must pin the path. The Russian and Armenian translations are confirmed in
   `OneFilePerLanguage/`.
5. **Warriner licence is still secondary-only.** The CC BY-NC-ND 3.0 claim comes only from the JULIELab XANEW README. The
   original page `crr.ugent.be/archives/1003` returns 404, the site says it is "under reconstruction", and the Wayback
   Machine and Springer are blocked here. The class `research-only` stands as the stricter reading. Brysbaert must be
   asked before any commercial or derivative use.

Everything else that drives decisions checks out:
- NRC VAD v2.1, EmoLex and Emotion Intensity are `needs-licence`, with verbatim terms. NRC VAD v2.1 is -1..1 with 54,801 terms.
- Warriner is on a 1-9 scale with 13,915 rows. EmoBank is 1-5 with 10,062 rows (8,062/1,000/1,000) and CC BY-SA 4.0.
- EmpatheticDialogues is CC BY-NC 4.0 (`research-only`).
- All 22 reachable download URLs return 200 with exactly the sizes R1 gave.
- SamLowe macro-F1 is 0.450 at 0.5 and 0.541 tuned. I recomputed both from the card's per-label tables.
